# AME Run Logs

One file per task:

```text
docs/ai/runs/<task-id>.md
```

Use `docs/ai/AME/templates/RUN_LOG.md`.

Rules:

- Record the task, risk, scope, and non-goals.
- Record approvals and evidence.
- Redact secrets and PII.
- Link commands, diffs, and test output.
- Record residual risk.
- Do not commit raw logs containing credentials.
