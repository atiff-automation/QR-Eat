# Backlog

Source of truth for work intake. Keep it small. Use an issue tracker if the project already has one; link to it here.

## Rules

- Every task has an ID.
- Every task has a type and risk.
- Every task has a status.
- Every task links to a run log when started.
- Respect a WIP limit.
- Do not start a task without acceptance criteria.
