# Accessibility Checklist

Target: WCAG 2.2 AA unless the project explicitly chooses another level.

## Perceivable

- [ ] Text alternatives for images/icons
- [ ] Captions/transcripts for media
- [ ] Meaningful sequence
- [ ] Colour not the only signal
- [ ] Contrast meets AA
- [ ] Text resizes without loss
- [ ] Reflow at 320 CSS px
- [ ] Non-text contrast
- [ ] Text spacing

## Operable

- [ ] Keyboard access to all controls
- [ ] No keyboard trap
- [ ] Focus visible
- [ ] Focus order logical
- [ ] Skip/bypass blocks
- [ ] Page titles
- [ ] Headings/labels
- [ ] Target size adequate
- [ ] Dragging has an alternative
- [ ] Motion can be reduced

## Understandable

- [ ] Language set
- [ ] Consistent navigation
- [ ] Consistent identification
- [ ] Error identification
- [ ] Labels/instructions
- [ ] Error suggestions
- [ ] Error prevention for legal/financial/data
- [ ] Redundant entry avoided
- [ ] Accessible authentication
- [ ] Help consistent

## Robust

- [ ] Name, role, value
- [ ] Status messages announced
- [ ] Works with assistive tech basics

## Testing

- [ ] Automated scan (partial)
- [ ] Keyboard-only pass
- [ ] Screen-reader smoke test
- [ ] Zoom/reflow
- [ ] Reduced motion
- [ ] Mobile/touch
- [ ] Error states
- [ ] Auth flow
- [ ] Payment flow if applicable

Do not claim full compliance from an automated tool.
