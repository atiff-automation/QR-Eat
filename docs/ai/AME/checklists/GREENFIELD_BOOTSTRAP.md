# Greenfield Bootstrap Checklist

## Product slice

- [ ] Target user identified
- [ ] Problem stated
- [ ] One-sentence outcome
- [ ] In-scope and out-of-scope
- [ ] Acceptance criteria
- [ ] Risk level
- [ ] Simplest architecture chosen

## Stack

- [ ] Language/framework
- [ ] Package manager
- [ ] Database
- [ ] Test framework
- [ ] Lint/typecheck
- [ ] Local run command
- [ ] CI
- [ ] Secrets/environment approach
- [ ] Deployment target

## Harness

- [ ] Repository created
- [ ] Build command works
- [ ] Test command works
- [ ] Lint/typecheck works
- [ ] CI runs
- [ ] Health check or smoke test
- [ ] First test fails for the right reason, then passes

## Kit

- [ ] Kit installed
- [ ] `PROJECT_PROFILE.md` filled
- [ ] `AGENTS.md` filled
- [ ] `GLOSSARY.md` started
- [ ] `BACKLOG.md` created
- [ ] `ACTIVE.md` created (pointer only; `Task: none` at rest)
- [ ] Run-log folder created
- [ ] Validation passed

## Walking skeleton

- [ ] One route or entry point
- [ ] One data path
- [ ] One test
- [ ] One response or UI
- [ ] Runs locally
- [ ] Deployed or runnable in staging

## First feature

- [ ] `/ame` used for the first L2/L3 feature, then the approved task implemented
- [ ] `/ame-resume` verified after a deliberate session restart
- [ ] UX flow if user-facing
- [ ] API contract if frontend/backend
- [ ] Independent verification
- [ ] Retro recorded
